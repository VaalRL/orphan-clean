Powerful Architecture

Say goodbye to package clutter, accidental deletions and shady scripts

We solve two pain points the open-source community has left unsolved for a decade: cross-project dependency auditing and fail-safe uninstallation.

🌳

DAG Transitive Dependency Closure

No more false positives! If a project declares pandas, the solver walks the dependency DAG and automatically protects the underlying numpy and pytz, so they are never mistaken for orphans.

🛡️

Three-Tier Safety Allowlist

A unique fail-safe triage: core system packages (Tier 1) are permanently locked against removal, CLI tools (Tier 2) get a separate review, and only pure libraries (Tier 3) may be cleaned.

💾

One-Click Snapshot Backups

Before any uninstall, a timestamped restore snapshot is always created in the background with pip freeze, so you can roll back painlessly with one click at any time.

🪟

100% Native Desktop Window

Built on Microsoft's official WebView2 window container. No browser tabs, no address bar, no clutter: open it when you need it and close the window when you're done.

🚀

Slim Down Tens of GB of Build Bloat

Not just Python! Deep-scan Rust target/ and Flutter build/ caches in one click. A single run typically reclaims 20 GB to 50 GB or more of precious disk space.

⚡

Zero Heavy External Dependencies

The core relies 100% on the Python standard library with no Node.js required. The single-file orphan-clean.exe is only 13MB and runs out of the box.

Safety First

Why not use a brute-force cleaner?

How orphan-clean compares with traditional cleanup approaches on safety:

Hard lock on core system packages (Tier 1) ❌ Easily removes pip / pywin32 by mistake ❌ Deletes everything, often breaking Python environments ✅ Core packages permanently locked (removal forbidden)

Quick Start

Up and running in one minute

Choose your favorite way to launch orphan-clean:

Download the portable single-file executable and run it right away (no Python installation needed):

https://github.com/VaalRL/orphan-clean/releases/latest/download/orphan-clean.exe

👉 Double-click orphan-clean.exe to open the native dark console instantly!

Audit and clean directly from the command line with Python:

python -m orphanclean.cli "C:\\Users\\User\\Downloads\\Git" --orphans

You can also launch the native desktop window: python -m orphanclean.gui

Clone from GitHub to try the latest features:

git clone https://github.com/VaalRL/orphan-clean.git
