Powerful Architecture

告別套件垃圾堆，拒絕誤刪與黑心腳本

我們解決了過去十年開源社群一直無法解決的「跨專案依賴審計」與「安全卸載防呆」痛點。

🌳

DAG 傳遞依賴閉包求解

徹底告別誤判！專案若宣告 pandas，系統會沿著依賴有向無環圖自動保護底層的 numpy 與 pytz，絕不誤當成孤兒套件。

🛡️

三層安全防禦白名單

獨創防呆分流機制：系統核心套件（Tier 1）永遠鎖定禁止移除；CLI 工具（Tier 2）獨立審閱；唯有純庫（Tier 3）才允許安全清理。

💾

一鍵快照自動備份保單

任何卸載操作前，強制在背景透過 pip freeze 生成包含時間戳記的還原快照，隨時提供一鍵無痛回滾。

🪟

100% 原生獨立桌面視窗

採用微軟官方 WebView2 視窗容器技術。完全不打開瀏覽器分頁、無網址列、無多餘雜項，關閉視窗即隨開隨關。

🚀

數十 GB 編譯贅肉大瘦身

不只管 Python！一鍵深度掃描 Rust 的 target/ 與 Flutter 的 build/ 暫存檔，單次通常能找回 20GB ~ 50GB 以上的寶貴硬碟空間。

⚡

零外部重型依賴架構

核心 100% 依賴 Python 內建標準庫，無需安裝 Node.js，單檔 orphan-clean.exe 僅 13MB，隨插即用。

Safety First

為什麼不該使用暴力清理工具？

比對 orphan-clean 與傳統清理方式的安全性差異：

核心能力與安全防護指標 傳統 pip-autoremove 一般磁碟清理器 (CCleaner等) orphan-clean (本專案)
跨專案全景掃描 ❌ 僅限單一指定套件 ❌ 完全看不懂程式碼依賴 ✅ 自動遞迴掃描硬碟數百個專案
系統核心套件強制鎖定 (Tier 1) ❌ 易誤刪 pip / pywin32 ❌ 暴力全殺，常毀損 Python 環境 ✅ 永久安全鎖定核心 (禁止刪除)
DAG 傳遞依賴安全閉包 ❌ 無跨專案全域圖譜 ❌ 無 ✅ 遞迴閉包求解，零誤殺
卸載前自動快照備份保單 ❌ 無備份直接刪除 ❌ 刪了就消失 ✅ 自動產生 pip freeze 回滾保單
Rust / Flutter 編譯贅肉掃描 ❌ 不支援 ❌ 常遺漏或權限報錯 ✅ 支援 target/ 與 build/ 清理
純原生桌面視窗 ＋ 終端 CLI ❌ 僅純 CLI ❌ 充滿廣告 ✅ 免費開源、極致純淨、原生視窗
Quick Start

一分鐘開箱即用

選擇您最喜歡的方式啟動 orphan-clean：

下載免安裝單一執行檔，隨插即用（免安裝 Python 亦可運行）：

https://github.com/VaalRL/orphan-clean/releases/latest/download/orphan-clean.exe

👉 雙擊 orphan-clean.exe 即可秒開純原生深色控制台！

在命令列中直接透過 Python 審計並清理：

python -m orphanclean.cli "C:\\Users\\User\\Downloads\\Git" --orphans

亦可啟動原生桌面視窗：python -m orphanclean.gui

從 GitHub 克隆並體驗最新功能：

git clone https://github.com/VaalRL/orphan-clean.git
